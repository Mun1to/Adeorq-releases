# Download · English

`data-content` keys. Version, date and size are painted by the JS from `data/release.json`:
never written by hand.

## descarga.eyebrow
Download

## descarga.titulo
Set up your cockpit in two minutes.

## descarga.lead
Installer for 64 bit Windows. You need the CLI you already use installed, because Adeorq works
through it: it asks for no keys and creates no account.

## descarga.boton
Download for Windows

## descarga.todas
See all versions

## descarga.meta.sistema
Windows 10 and 11 · x64

## descarga.nota
Windows may warn you that the installer comes from an unknown publisher. That is the normal
SmartScreen notice for a young app with few downloads: <a href="#faq">the questions</a> explain
how to check the package is ours.

## descarga.gratis
Free, built in the open. No account, no 14 day trial, no card.

## JS state strings

- While loading: `looking for the latest version`
- No data available: `Go to the downloads page`
- Version label: `v{version}`
- Date label: `published on {date}`
- Size label: `{size}`
