## roadmap.0.texto
Right now the card positions and the arrows chaining them are lost when the app closes. It is

## roadmap.1.titulo
Sessions from the other CLIs

## roadmap.1.texto
Claude Code stores its conversations in files, which is why they can be read. Antigravity,
Codex and Gemini each store theirs their own way, so every one has to be studied on its own.
They arrive as they become readable without guesswork.

## roadmap.2.titulo
A signed installer

## roadmap.2.texto
So Windows stops warning about an unknown publisher on first install. It needs a code signing
certificate, and that paperwork is the blocker, not the work.

## roadmap.3.titulo
macOS and Linux

## roadmap.3.texto
The terminals rely on ConPTY, which is a Windows thing, so a port is real work and not a box to
tick. If you want it, say so: that is what will decide it.
