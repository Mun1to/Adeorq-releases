# Features · English

`data-content` keys. Five cards, same order as the Spanish file.

## features.titulo
A cockpit for directing agents, not another terminal window.

## features.lead
Every piece is here because it was missing during real work, not because it looked good on a
feature list.

---

## features.conpty.titulo
Real terminals, not an imitation

## features.conpty.texto
Each pane runs the same console engine Windows itself uses. Colours, redraws, Ctrl+C, history
and any tool that expects a real terminal all work as they should. Rendering goes through the
GPU, so thousands of lines will not choke the window.

## features.conpty.item1
PowerShell, CMD or whatever shell you use, with your PATH and your profile

## features.conpty.item2
The pseudoterminal resizes for real, with no broken lines

## features.conpty.item3
Copy, paste, and drop an image straight into the agent

---

## features.sesiones.titulo
Your Claude Code sessions, in plain sight

## features.sesiones.texto
Adeorq reads what the CLI already stores on your machine: which sessions you have, in which
project, what they were about, which are still alive and which are waiting on you. No API keys,
no sign up, and your code never leaves the computer.

## features.sesiones.item1
Title, project and real state for every session

## features.sesiones.item2
Pick up where you left off in one click, memory included

## features.sesiones.item3
Warns you about uncommitted changes before archiving anything

---

## features.escuadron.titulo
The squad works, you direct

## features.escuadron.texto
Several agents at once, each in its own pane and its own folder, all on the same screen. When
one finishes its turn its pane lights up, so you know who needs you without checking window by
window.

## features.escuadron.item1
A grid of panes you can split right or down

## features.escuadron.item2
A visible cue when an agent is done and waiting

## features.escuadron.item3
One colour per project, so you never lose track

---

## features.agenda.titulo
Loose ideas do not get lost

## features.agenda.texto
While you work, things come up that are not the job at hand. Instead of interrupting you, they
land in a tray you review whenever you want: keep what is useful, drop the rest. Agents
propose, you decide.

## features.agenda.item1
A tray of ideas and next steps, per project

## features.agenda.item2
Accept or discard them one by one

## features.agenda.item3
An agent can propose without touching a single credential of yours

---

## features.sistema.titulo
Starts with Windows, updates itself

## features.sistema.texto
Turn the computer on and the cockpit is already up. New versions arrive signed, tell you what
changed and install when you say so, with no hunting for an installer every time.

## features.sistema.item1
Start with the system, optional and reversible in one click

## features.sistema.item2
Signed updates, with a notice and the release notes

## features.sistema.item3
A 3.5 MB native app, with no browser packed inside
