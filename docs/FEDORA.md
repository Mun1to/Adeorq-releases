# Adeorq en Fedora

Este documento explica cómo compilar y ejecutar Adeorq en distribuciones Fedora 40+.

## Requisitos del sistema

- **Fedora 40 o superior** (recomendado)
- **glibc 2.35 o superior** (Fedora 40+ cumple con esto)
- **Compositor gráfico** (GNOME o KDE modernos para la ventana translúcida)

chmod +x setup-fedora.sh
